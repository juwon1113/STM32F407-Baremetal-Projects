# 01. Maze Runner

조이스틱으로 LCD 위 5 × 5 격자의 마우스(파란 사각형)를 (0,0)에서 목표 (4,4)까지 옮기는 게임입니다.

## 동작
- SW7: 시작, SW0: 초기화
- 조이스틱 상하좌우로 한 칸씩 이동. 이동 방향에 따라 LED1~4 중 하나를 켜고, 방향별 이동 횟수와 현재 좌표를 LCD에 표시
- 격자 밖으로 나가려 하면 이동하지 않고 부저 2회, 목표에 도착하면 부저 3회 후 입력 잠금

## 사용한 주변장치

| 주변장치 | 핀 | 용도 |
| --- | --- | --- |
| GPIO 출력 | PG0~7 | LED |
| GPIO 출력 | PF9 | 부저 |
| GPIO 입력 | PH8~15 | 스위치 |
| GPIO 입력 | PI5~9 | 조이스틱 (폴링) |

## 구현 포인트
- `MODER`, `OTYPER`, `OSPEEDR`, `PUPDR`를 직접 설정해 입출력 모드 구성
- LED는 `BSRRL`/`BSRRH`로 한 비트씩만 변경: 읽고-고치고-쓰는 과정 없이 원자적으로 바뀌어서 다른 비트에 영향이 없음
- 스위치와 조이스틱은 상태 플래그와 10 ms 지연으로 디바운싱하고, 누르고 있는 동안은 한 번만 입력으로 처리
- 이동할 때 이전 위치의 마우스를 지우고 미로 선을 다시 그린 뒤 새 위치에 그림
