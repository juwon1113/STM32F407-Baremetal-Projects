# 04. 인터스텔라 시계

지구 시계와, 시간이 다르게 흐르는 밀러 행성 시계를 함께 표시하는 프로그램입니다. 밀러 시계의 진행 속도를 실행 중에 바꿀 수 있습니다.

## 동작
- 두 시계 모두 23:50에서 시작, 100 ms마다 1분씩 증가
- SW6 (EXTI14): 밀러 시계 주기를 100 → 200 → 500 ms로 변경, LCD에 주기 표시
- SW7 (EXTI15): 두 시계를 00:00으로 초기화 (LED7과 부저로 알림)

## 사용한 주변장치

| 주변장치 | 설정 | 용도 |
| --- | --- | --- |
| TIM5 | PSC 42, ARR 200000 (32비트), 업데이트 인터럽트 100 ms | 지구 시계 |
| TIM4 CH2 | PSC 8400, OC 토글 모드, CC2 인터럽트, PB7 출력 | 밀러 시계, 주기 확인용 펄스 |
| EXTI14, 15 | PH14, PH15 | 주기 변경, 초기화 |

## 구현 포인트
- 타이머 주기 계산: 84 MHz ÷ 8400 = 10 kHz(0.1 ms), × ARR 1000 = 100 ms
- 주기 변경 순서: 카운터 정지(`CEN = 0`) → `ARR` 변경 → `EGR`의 UG로 카운터와 레지스터 갱신 → 다시 시작
- `ARPE = 1`이면 새 ARR이 다음 주기부터 적용되므로, UG로 즉시 반영
- 인터럽트 핸들러에서는 플래그만 세우고, 실제 처리(주기 변경, 화면 갱신)는 main 루프에서 수행해 핸들러를 짧게 유지
- PB7로 토글 펄스가 나와서 오실로스코프로 주기 변경을 확인 가능
