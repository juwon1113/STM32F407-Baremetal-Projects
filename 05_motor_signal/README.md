# 05. 스텝·DC 모터 구동 신호 발생

스위치로 스텝모터 위치 명령을, 가변저항으로 DC 모터 토크 명령을 입력받아 각각에 맞는 구동 펄스를 만드는 프로그램입니다.

## 동작
- **스텝모터**: SW3을 누를 때마다 위치 명령이 0 → 1 → 2 → 3 → 0으로 변하고, 명령이 바뀌면 그 값의 2배만큼 펄스를 출력
- **DC 모터**: 가변저항 전압을 4단계(0~3)로 나눠 PWM 듀티를 0, 30, 60, 90%로 변경 (실습에서는 부저로 확인)

## 사용한 주변장치

| 주변장치 | 설정 | 용도 |
| --- | --- | --- |
| TIM5 CH2 | **외부 클럭 모드 1**, TI2FP2 하강 엣지, ARR 3 | SW3 누름 횟수를 타이머가 직접 셈 |
| TIM4 | 100 ms 업데이트 인터럽트 | 위치 명령 확인, 변경 시 펄스 출력 시작 |
| TIM1 CH3 | OC 토글 모드, CC3 인터럽트, PE13 출력 | 정해진 개수만큼 스텝 펄스 출력 후 정지 |
| ADC3 IN1 | 10비트, EOC 인터럽트 | 가변저항 전압 → 토크 명령 |
| TIM14 CH1 | PWM 모드 2, 주기 400 µs, PF9 출력 | DC 모터 PWM |

## 구현 포인트
- **외부 클럭 모드**: 스위치 신호를 타이머 입력(TI2)으로 넣고 `SMCR`의 SMS = 111, TS = TI2FP2로 설정해, CPU가 세지 않아도 타이머 카운터가 누른 횟수가 됨. `ARR = 3`이라 0~3에서 자동으로 돌아감
- **펄스 개수 출력**: TIM1 CC3 인터럽트마다 횟수를 세다가 목표에 도달하면 출력(`CC3E`)과 카운터(`CEN`)를 꺼서 정확한 개수만 출력
- **PWM 모드 2**: CCR보다 작은 구간이 비활성, 큰 구간이 활성. 극성 설정과 함께 듀티 계산
- ADC 결과를 전압으로 환산: `전압 = ADC 값 × 3.3 / 1023`

## 다시 본다면
- TIM4 인터럽트 핸들러 안에서 LCD 출력까지 해서 핸들러가 길어짐. 플래그만 세우고 main에서 출력하는 편이 좋음
- `SMCR`의 TS 주석은 `0b101`인데 실제 값은 `6`(0b110, TI2FP2). 값이 맞고 주석이 틀림
