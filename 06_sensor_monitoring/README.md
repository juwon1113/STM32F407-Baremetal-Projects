# 06. USART 통신을 이용한 센서 모니터링

온도센서 3개의 값을 주기적으로 읽어 LCD에 숫자와 막대그래프로 표시하고, PC의 요청에 따라 USART로 전송하는 프로그램입니다.

## 동작
- 400 ms마다 센서 3개를 자동으로 AD 변환
  - 센서 1: 키트 가변저항 (ADC1_IN1)
  - 센서 2: 외부 입력 (ADC1_IN8)
  - 센서 3: MCU 내부 온도센서 (ADC1_IN16)
- 전압과 온도를 LCD에 표시하고 온도에 비례하는 막대 표시
- PC 터미널에서 `1`, `2`, `3`을 보내면 해당 센서 온도를 `"25 "` 형식으로 응답

## 사용한 주변장치

| 주변장치 | 설정 | 용도 |
| --- | --- | --- |
| ADC1 | 12비트, **스캔 모드 3채널**, 샘플링 480 사이클 | 센서 3개 변환 |
| TIM1 CH2 | OC 토글, 400 ms, ADC 외부 트리거(`EXTSEL` = TIM1_CC2) | AD 변환 자동 시작 |
| DMA2 Stream0 | 주변장치 → 메모리, 하프워드, 메모리 주소 증가, **순환 모드**, `NDTR = 3` | 변환 결과를 배열에 자동 저장 |
| USART1 | 38400 bps, 9비트(데이터 8 + 패리티), 홀수 패리티, RX 인터럽트, TX 폴링 | PC 통신 |

## 구현 포인트
- **CPU 개입 없는 측정**: 타이머가 ADC를 시작하고, 변환 결과는 DMA가 배열로 옮겨서 main은 배열만 읽으면 됨
- 스캔 모드의 변환 순서는 `SQR3`에 채널 번호를 순위별로 등록해서 지정
- 내부 온도센서는 `ADC->CCR`의 TSVREFE를 켜야 동작하고, 데이터시트의 V25와 Avg_Slope로 온도 계산: `(Vsense − V25) / Avg_Slope + 25`
- 센서 1, 2의 온도는 과제에서 주어진 관계식 `T = 3.5 × V² + 1`로 계산
- `BRR`은 APB2 클럭과 보레이트로 계산하는 함수로 설정
