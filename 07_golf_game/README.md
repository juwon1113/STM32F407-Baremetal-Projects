# 07. Golf Game

키트를 기울이면 가속도센서 값에 따라 LCD 위의 공이 굴러가고, 3개의 홀에 순서대로 넣는 시간을 재는 게임입니다.

## 동작
- SW4 (EXTI12): 게임 시작. 스톱워치가 0.1초 단위로 시작되고 공이 움직이기 시작
- 키트를 기울이면 기운 방향으로 공이 이동하고, 많이 기울일수록 빠르게 이동
- 공이 벽에 닿으면 벽을 넘지 않고 벽을 따라서만 이동
- 1 → 2 → 3번 홀 순서대로 들어가야 인정되고, 들어간 홀은 노란색에서 파란색으로 변경
- 3번 홀에 들어가면 스톱워치 정지
- 가속도 X, Y, Z 값을 부호와 함께 g 단위로 LCD에 표시

## 사용한 주변장치

| 주변장치 | 설정 | 용도 |
| --- | --- | --- |
| SPI1 | 마스터, 8비트, MSB 먼저, 전이중, 소프트웨어 NSS, CPOL = 1, CPHA = 1, 84 MHz ÷ 32 | 가속도센서 통신 |
| TIM11 CH1 | OC 모드, CC 인터럽트 200 ms | 가속도 측정 주기 |
| TIM6 | 업데이트 인터럽트 100 ms | 스톱워치 |
| EXTI12 | PH12 (SW4) | 게임 시작 |

## 구현 포인트
- **SPI 초기화를 레지스터로 직접 설정**: `SPI1->CR1`에서 마스터 모드, 데이터 크기, 비트 순서, 클럭 극성과 위상(SPI 모드 3), 보레이트 분주를 각각 설정. 센서와 주고받는 함수(`ACC.c`)는 수업에서 제공
- 센서 원시값(−32768~32767)을 ±2 g 범위에 맞춰 g 단위로 환산해 소수 첫째 자리까지 표시
- 인터럽트에서는 측정 시점 플래그만 세우고, SPI 통신과 화면 갱신은 main 루프에서 처리
- **기울기에 따른 속도**: 공을 한 픽셀 옮긴 뒤 기다리는 시간을 `20 − |가속도| × 2` ms로 정해, 많이 기울일수록 짧게 기다려 빠르게 굴러가게 함
- **벽 처리**: 좌표를 경기장 경계에서 멈추고, 벽에 붙어 있을 때는 벽과 나란한 축의 가속도로만 속도를 정해 벽을 따라 미끄러지듯 이동
- 공이 지나가며 홀 그림을 지우지 않도록 매 이동마다 홀을 다시 그림

## 다시 본다면
- 지금은 가속도의 부호만으로 한 픽셀씩 움직이고 크기는 대기 시간에만 반영함. 속도를 누적하는 방식(가속도 → 속도 → 위치)으로 바꾸면 쟁반 위 구슬처럼 더 자연스럽게 움직일 것
