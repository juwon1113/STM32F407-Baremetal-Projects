# 08. 자동차 추종 시스템 (텀 프로젝트)

앞차와의 거리, 인도와의 거리를 측정해 따라가는 차(추종차)의 속도와 방향을 PWM으로 제어하는 시스템입니다. 실제 모터 대신 LED와 부저로 PWM 출력을 확인했습니다.

## 동작
- **거리 측정**: 가변저항 두 개를 거리센서로 사용. 앞차와의 거리 D1(3~19 m), 인도와의 거리 D2(0~3 m)를 LCD에 숫자와 막대로 표시
- **속도 제어**: D1이 멀수록 엔진 PWM 듀티를 10~90%로 높임
- **방향 제어**: D2에 따라 핸들 PWM을 바꾸고 L, F, R로 표시
- **시동**: SW4/SW6 또는 PC에서 `M`/`S` 문자로 MOVE/STOP 전환
- **상태 저장**: MOVE/STOP 상태를 FRAM에 저장해 리셋 후에도 이전 상태로 복귀
- MOVE 상태에서 400 ms마다 PC로 D1 거리 전송

## 사용한 주변장치

| 주변장치 | 설정 | 용도 |
| --- | --- | --- |
| ADC3 | 10비트, **스캔 모드 2채널** (IN1 PA1, IN9 PF3), EOC 인터럽트 | 거리센서 두 개 |
| TIM1 CH3 | OC 모드, 400 ms, ADC 외부 트리거 (양쪽 엣지) | AD 변환 자동 시작 |
| DMA2 Stream0 | 채널 2, 순환 모드, `NDTR = 2` | 변환 결과를 배열에 자동 저장 |
| TIM4 CH2 | PWM 모드 1, 주기 5 s (0.2 Hz), PB7 | 엔진 속도 PWM (외부 LED로 확인) |
| TIM14 CH1 | PWM 모드 1, 주기 400 µs, PF9 | 핸들 방향 PWM (부저로 확인) |
| USART1 | 19200 bps, 8비트, 패리티 없음, RX 인터럽트, TX 폴링 | PC 명령 수신, 거리 전송 |
| EXTI12, 14 | PH12 (SW4), PH14 (SW6) | MOVE, STOP |
| FRAM | 1201번지 | 주행 상태 저장 |

## 구현 포인트
- 06번 센서 모니터링의 구조(타이머 트리거 → ADC 스캔 → DMA)를 확장해, 스캔이 끝나면 EOC 인터럽트에서 전압 → 거리 환산과 화면 갱신까지 처리
- 거리 환산: D1 = 전압 × 5 + 3, D2 = 전압의 정수 부분
- PWM 두 개를 서로 다른 타이머로 출력: 느린 PWM(5 s 주기)은 LED가 켜지는 시간으로 듀티를 눈으로 확인할 수 있게 하고, 빠른 PWM(400 µs)은 부저 소리로 확인
- 스위치(EXTI)와 PC 명령(USART) 두 경로 모두에서 같은 상태 전환을 하고, 전환할 때마다 FRAM에 저장
- 부팅 시 FRAM에서 상태를 읽어 STOP/MOVE 화면과 출력 상태를 그대로 복원

## 다시 본다면
- FRAM 쓰기가 인터럽트 핸들러 안에서 실행됨. 플래그만 세우고 main에서 저장하면 핸들러가 짧아짐
