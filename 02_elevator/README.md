# 02. 엘리베이터 제어

0~5층 엘리베이터를 스위치로 호출하고, 인터럽트로 일시 정지와 속도 변경을 하는 프로그램입니다.

## 동작
- SW0~5로 목표층 입력 → LED가 1초 간격으로 한 층씩 이동, LCD에 현재층·목표층 표시, 도착 시 부저 3회
- SW6 (EXTI14): 속도 변경. 시스템 클럭을 168 MHz ↔ 84 MHz로 전환
- SW7 (EXTI15): 이동 중 4초간 정지 (Hold)

## 사용한 주변장치

| 주변장치 | 설정 | 용도 |
| --- | --- | --- |
| GPIO | PG0~7, PH8~15, PF9 | LED, 스위치, 부저 |
| EXTI14, 15 | PH14, PH15 하강 엣지 | 속도 변경, Hold |
| RCC | HSE + PLL (M = 8 또는 16, N = 336, P = 2) | 시스템 클럭 변경 |

## 구현 포인트
- `SYSCFG->EXTICR`로 EXTI14, 15번 줄을 GPIOH에 연결하고, `FTSR`, `IMR`, `NVIC->ISER`로 인터럽트 활성화
- PLL 출력 = 8 MHz ÷ M × N ÷ P. M을 8 → 16으로 바꾸면 168 MHz → 84 MHz
- 클럭을 바꿀 때 시스템 클럭을 잠시 HSI로 돌리고, PLL을 끄고 설정을 바꾼 뒤 다시 켜는 순서로 진행
- 지연 함수가 반복문 기반이라 클럭이 절반이 되면 모든 시간이 두 배로 늘어남 (과제에서 의도한 동작)

## 다시 본다면
- 클럭 변경 시 PLL이 안정될 때까지(`PLLRDY`) 기다리는 단계가 빠져 있음. RM0090의 RCC 절차를 따르는 것이 안전
- 반복문 지연은 클럭에 따라 시간이 바뀌므로, 실제 제품이라면 타이머로 시간을 재야 함
- Hold 동작(4초 대기)이 인터럽트 핸들러 안에서 실행되어 그동안 다른 인터럽트 처리가 막힘
