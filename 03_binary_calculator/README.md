# 03. 이진 연산기 (텀 프로젝트)

2비트 피연산자 두 개로 덧셈, 뺄셈, 곱셈, AND, OR, XOR을 계산하고 결과를 FRAM에 저장하는 계산기입니다.

## 동작
- SW2~5: 피연산자 A, B의 각 비트 입력 (누를 때마다 0/1 전환)
- 조이스틱 오른쪽 (EXTI8): 연산자 전환 (+ → − → × → & → | → ^)
- SW1 (EXTI9): 계산 후 결과를 부호와 함께 2~4비트로 표시
- 조이스틱 아래 (EXTI7): 연속 증가 모드. 0.5초마다 결과 +1
- SW6 (EXTI14): 연속 증가 모드 탈출
- 연산자와 결과를 FRAM에 저장해서 리셋 후에도 복원

## 사용한 주변장치

| 주변장치 | 설정 | 용도 |
| --- | --- | --- |
| EXTI7, 8 | GPIOI (조이스틱) | 연속 증가, 연산자 전환 |
| EXTI9, 14 | GPIOH (스위치) | 계산, 연속 모드 탈출 |
| NVIC | EXTI15_10 우선순위를 EXTI9_5보다 높게 | 인터럽트 선점 |
| FRAM | MB85RS64 (8 KB, SPI2), 527번지(연산자), 528번지(결과) | 전원이 꺼져도 값 유지 (드라이버는 수업 제공) |

## 구현 포인트
- **인터럽트 선점**: 연속 증가 모드는 EXTI7 핸들러 안의 무한 루프로 동작하고(과제 요구사항), 탈출은 EXTI14 핸들러가 플래그를 바꿔서 함. EXTI14가 EXTI7 루프를 끊고 들어오려면 우선순위가 더 높아야 해서 `NVIC->IP`로 EXTI15_10을 `0xE0`, EXTI9_5를 `0xF0`으로 설정 (값이 작을수록 우선순위가 높음)
- 서로 다른 포트(GPIOI, GPIOH)를 `SYSCFG->EXTICR`로 각각 EXTI 줄에 연결
- 뺄셈 결과가 음수일 수 있어서 FRAM에서 읽을 때 `int8_t`로 형변환해 부호를 복원

## 다시 본다면
- `NVIC->IP` 줄의 주석(High/Low)이 실제와 반대로 적혀 있음. 값은 올바름
- 다른 인터럽트에서 바뀌는 `flag`는 `volatile`로 선언하는 것이 맞음. 지금은 루프 안에 함수 호출이 있어 우연히 동작
